# playX-mas

성탄 이야기 QR 챌린지의 정적 모바일 웹 프로토타입입니다. 기획과 운영 가정은 [PLAN](docs/PLAN.md)을 참고하세요.

## 로컬 실행

Python 3가 설치된 환경에서 저장소 폴더에서 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000/`을 엽니다. JSON을 불러오므로 파일을 직접 여는 `file://` 방식은 사용하지 않습니다. 같은 네트워크의 휴대폰에서는 컴퓨터의 접근 가능한 IP 주소로 열고 방화벽을 확인하세요. 행사에 사용할 주소와 호스팅은 별도 결정이 필요합니다. 서버가 실행되는 환경에서도 최초 접속과 각 페이지·데이터 로딩에는 연결이 필요하며, 오프라인 캐시는 제공하지 않습니다. 연결이 안 되면 인쇄된 문제·정답·진행표를 사용하세요.

## 사용 및 설정

팀 이름에는 개인 이름을 넣지 않습니다. 지점 QR 주소로 접속하거나 시작 화면에서 지점을 선택하고, 아이용 기본 미션을 모두 완료하면 완주합니다. 어른용 심화는 선택입니다. 행동 미션과 리더용 정답은 리더 코드로 확인합니다. 기록은 해당 브라우저의 localStorage에만 남으며 기기 변경이나 브라우저 데이터 삭제 시 사라질 수 있습니다. 종료 후 화면의 기록 삭제 버튼을 사용하세요.

- `missions.json`: 지점 ID, 이야기, 문제, 선택지, 정답과 힌트. `type`이 `action`이면 리더 확인 활동입니다.
- `config.json`: 제목, 리더 코드(초기값 `1224`), 저장 키. 코드는 브라우저에 공개되므로 보안 수단이 아닙니다.
- `urls.html`: 현재 접속 주소 기준 시작·지점별 URL 목록과 인쇄 버튼. QR 이미지는 별도로 생성해야 하며 실제 인쇄물 스캔을 확인하세요. localhost 주소는 다른 기기에서 쓸 수 없습니다.

미션과 답은 초안이므로 행사 전 담당 교사의 검토가 필요합니다. 실제 기기, 현장 네트워크 및 인쇄 QR 검증은 아직 필요합니다.

## 테스트

Node.js가 설치된 환경에서 `node --test`를 실행합니다. 외부 패키지는 필요하지 않습니다.
