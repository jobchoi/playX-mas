# Rt탐험대 (가칭)

[확정] 「별빛 탐험대: 흩어진 약속을 찾아서」를 바탕으로 한 정적 QR 어드벤처 프로토타입입니다. 이름은 추후 변경할 수 있고 이야기와 말씀은 담당 교사 검토 전 초안입니다. [기획](docs/PLAN.md)을 참고하세요.

## 실행과 진행

외부 패키지나 빌드 없이 Python 3가 있다면 저장소에서 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000/`을 엽니다. JSON과 게임 모듈을 불러오므로 `file://`로 열지 않습니다. 시작 이야기에서 기본 지점을 선택하거나 인쇄된 지점 QR 주소로 이동합니다. 아이용 게임에 성공하면 조각을 얻고 기본 조각을 모두 모으면 피날레가 열립니다. 어른용은 선택이며 숨겨진 QR의 보너스 조각도 필수가 아닙니다. 조각과 완료 기록은 같은 브라우저의 localStorage에 저장되며 기기 교체나 데이터 삭제 시 사라집니다. 종료 후 기록 삭제 버튼을 사용하세요.

`urls.html`은 현재 주소를 기준으로 시작·기본·숨은 지점 주소를 보여 줍니다. 숨은 주소가 참여자에게 보이지 않도록 리더가 관리하세요. QR 이미지는 별도로 만들고 실제 인쇄물과 기기에서 검증해야 합니다. 웹 앱은 카메라·모션 권한을 요청하지 않습니다. QR 스캔에는 기기의 별도 스캐너를 사용합니다. 최초 접속과 각 파일 로딩에 연결이 필요하고 오프라인 캐시는 없습니다. 연결 실패에 대비해 종이 문제와 진행표를 준비하세요.

## 데이터 추가

- `config.json`의 `title` 한 곳에서 게임 이름을 바꿉니다. 시작 이야기, 안전 안내, 피날레 문구와 말씀 출처도 여기서 편집합니다.
- `missions.json` 배열에 고유한 `id`, `title`, `story`, 게임 종류 `game`, `child`·`adult` 데이터를 넣습니다. `fragment`의 고유한 숫자 `order`와 `text`가 조각과 피날레 순서를 정합니다. `bonus: true`이면 시작 목록에 숨고 피날레 필수가 아닙니다. 각 게임의 데이터 형태는 기존 항목을 참고하세요. 기본 지점에는 반드시 조각을 지정합니다.
- 새 게임은 `games/<game>.js`에 추가합니다. 브라우저에서 `window.MiniGames[game]`에 `{ mount, correct }`를 등록하고, `mount(container, 난이도데이터, finish)`에서 정답 여부를 `finish(true 또는 false)`로 전달합니다. Node 테스트에서 불러올 수 있도록 CommonJS도 내보내세요. 기존 모듈을 예시로 사용할 수 있습니다. 지점 JSON의 `game`에 모듈 파일명을 지정하면 자동으로 불러옵니다.
- 말씀은 현재 검토용 문장입니다. 지점의 조각을 순서대로 수정하고 `config.json`의 출처도 변경하세요. 보너스 조각은 완성 문장에 포함되지 않습니다.

## 테스트

Node.js에서 `node --test`를 실행합니다. 외부 패키지는 필요하지 않습니다. 실제 기기, 인쇄 QR, 현장 네트워크 및 교사 콘텐츠 검토가 필요합니다.
